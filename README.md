# Inglés profesional · DAW Study Lab

Web estática de práctica B1/B2 en español de España. Incluye vocabulario, gramática, ejercicios autocorregibles, reading, listening con lectura en voz alta, tarjetas interactivas, práctica oral con grabación local y borradores de writing.

## Publicar en GitHub Pages

1. Sube `index.html` a la raíz de tu repositorio (puedes añadir también este README).
2. En GitHub, abre **Settings → Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**, la rama principal y la carpeta `/ (root)`; guarda los cambios.
4. Abre la URL que te indique GitHub Pages. La grabación del micrófono necesita permiso y una conexión HTTPS.

No necesita servidor ni bibliotecas externas. El progreso y los borradores se guardan en el almacenamiento local del navegador y no se sincronizan entre dispositivos.
